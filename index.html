• “Valor inicial / referência”: em geral, o dado imediatamente anterior comparável ou o último valor de 2025, para dar noção de evolução.
• “Status”: classificação editorial simples (melhorou / piorou / estável), não substitui análise contextual. Itens com “pending” indicam dados de meses anteriores ou metodologia alterada.
• Picanha: não há pesquisa nacional mensal oficial consolidada para out/2026. Usei os dois dados disponíveis com data (Neogrid abr/2026 e Mercado Mineiro out/2026 local).
• Obras paradas: o TCU mudou o critério de classificação; a comparação direta entre 11.469 (2025) e 4.215 (2026) não significa que todas foram retomadas.
• Queimadas: o último boletim consolidado do INPE disponível era junho/2026; outubro ainda não tinha fechamento oficial.
